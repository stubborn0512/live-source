# live-source

自动发现、检测、筛选并生成可供本地播放器订阅的直播源。

## 项目说明

本项目为公益性质的个人项目，免费提供服务。

由于直播源、网络环境及服务器状态等因素影响，播放速度和稳定性可能存在波动，无法保证每次均能秒开或持续稳定播放，敬请理解。

### 源维护

项目会通过 GitHub Actions **每日自动检测和更新可用直播源**，对直播地址进行连通性、媒体质量等检查；源列表变化后会重新筛选可用线路。自动检测并不意味着所有频道始终可用，最终播放体验仍受上游直播源和网络环境影响。

## 第一阶段

当前先实现 CCTV 公开直播接口的动态解析：

```
CCTV 频道定义
    ↓
公开直播接口
    ↓
获取当前 HLS 地址
    ↓
ffprobe 实际探测
    ↓
筛选真实 1920×1080+
    ↓
生成 output/1080p.m3u
```

播放器不需要保存不断变化的实际直播 URL，只需要订阅固定的播放列表地址。

### 当前订阅地址

**推荐：故障自动切换版（一个频道只显示一次）**

```
https://live-source-gateway.onrender.com/playlist.m3u
```

播放器通过网关访问频道；同一频道的多个已验证源由网关按顺序自动故障切换，不再把同一频道显示成“线路1/线路2”两个频道。

**静态备用版**

```
https://raw.githubusercontent.com/stubborn0512/live-source/main/output/1080p.m3u
```

静态版保留多线路条目，适合网关不可用时直接使用。

## 项目结构

- `providers/`：直播源提供器
- `checker/`：连通性和媒体质量检测
- `generator/`：M3U 生成
- `data/`：频道配置
- `output/`：静态播放器订阅文件
- `gateway/`：单频道故障切换网关
- `.github/workflows/`：自动更新与网关冒烟测试

## 设计原则

1. 优先使用公开、合法可访问的官方/授权来源。
2. 不绕过 DRM、鉴权、地区限制或访问控制。
3. 不把“HTTP 200”当作直播有效。
4. 用 ffprobe 检查实际视频流。
5. “1080P”以实际探测结果为准，而不是频道名称。
6. 源短暂失败时保留历史状态，避免瞬时网络抖动造成误删。
7. 最终播放器只订阅固定的 M3U 地址。

## 本地运行

需要 Python 3.11+ 和 FFmpeg：

```bash
pip install -r requirements.txt
python main.py
```

生成：

```
output/1080p.m3u
output/status.json
```
