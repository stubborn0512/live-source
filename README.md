# 果幕｜live-source

**果幕**是一款简单的电视直播小程序，支持 CCTV、卫视频道播放。直播源会定期检测和更新，遇到线路异常时会自动尝试切换。项目免费使用，主要作为个人维护的公益项目。

> 小程序名称：**果幕**  
> GitHub 项目：**live-source**

## 项目说明

本项目为公益性质的个人项目，免费提供服务。

由于直播源、网络环境及服务器状态等因素影响，播放速度和稳定性可能存在波动，无法保证每次均能秒开或持续稳定播放，敬请理解。

### 源维护

直播源由独立的私有核心项目定期检测、筛选和更新。当前公开仓库主要提供项目说明、公开订阅结果和问题反馈。

检测过程中会对直播地址的连通性、媒体信息等进行实际检查；自动检测并不意味着所有频道始终可用，最终播放体验仍受上游直播源和网络环境影响。

## 当前订阅地址

**推荐：故障自动切换版**

```
https://live-source-gateway.onrender.com/playlist.m3u
```

播放器通过网关访问频道；同一频道的多个已验证源由网关按顺序进行故障切换。

**静态备用版**

```
https://raw.githubusercontent.com/stubborn0512/live-source/main/output/1080p.m3u
```

静态版保留多线路条目，适合网关暂时不可用时直接使用。

## 项目内容

当前公开仓库主要包含：

- `output/`：自动生成的直播源结果
- `assets/`：项目图片资源
- `.github/workflows/test-gateway.yml`：公开网关冒烟测试
- `README.md`：项目说明

核心直播源解析、检测、筛选和网关代码保存在私有仓库，不在本公开仓库中提供。
